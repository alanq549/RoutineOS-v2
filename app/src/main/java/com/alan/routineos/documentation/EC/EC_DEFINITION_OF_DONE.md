# Definition of Done — por Epic/Chapter (EC)

Un EC solo puede marcarse como COMPLETED si cumple TODOS estos puntos:
- [ ] Compila sin warnings nuevos
- [ ] Tests existentes pasan (unitarios + los que aplique)
- [ ] Checklist de ARCHITECTURE_INVARIANTS.md revisado y sin violaciones
- [ ] Si se usó Fake*Repository, está registrado en MOCK_DATA_STATUS.md
- [ ] Lecciones aprendidas documentadas en el spec del EC
