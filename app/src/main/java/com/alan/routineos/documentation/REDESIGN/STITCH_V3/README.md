# RoutineOS Redesign - Stitch V3 References

Este directorio contiene las referencias visuales y técnicas descargadas de Stitch para la Fase 1 del rediseño de RoutineOS.

## Estructura
- `design_system/`: Guías de estilo y tokens base.
- `today/`: Diseños para la ejecución diaria y timeline.
- `planning/`: Diseños para la vista semanal y gestión de rutinas.
- `system/`: Diseños para la vista estructural de sistemas.
- `stats/`: Diseños para el seguimiento de cumplimiento y ritmo.
- `account/`: Diseños para el perfil y configuración.
